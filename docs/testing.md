# 验收

`npm test` 使用虚拟数据和接口替身，不消耗API额度，覆盖错误日期/住宿/重复城市、景点规范去重、每城景点与美食数量、路由失效、文本注入、地图组件、确认哈希、高德3次/秒限速与重试、Redfox美食查询词、来源筛选和隐私扫描。

`npm run demo` 生成固定模板样例。`node scripts/browser-check.mjs` 使用本机Chrome与Node内置WebSocket，无第三方依赖，在360/390/430/1100px检查布局、地图图标、天气正常和失败、导航选中、便利贴操作与持久化、减少动态效果；截图及报告写入被Git忽略的output/qa。

浏览器检查需要Node22+和本机Chrome（可用CHROME_BIN指定）。无浏览器的环境应说明未完成视觉验收，不伪造截图。

真实出行发布前另外核验：地点入口/停车坐标、闭园与预约、路线方案和当天安排、来源真实性、移动端高德/小红书App跳转、iOS真机动画与可读性。模拟触控浏览器不能替代真机。付费接口的实际授权和额度也需要用户自己的账号验证。

自动地图排版无法找到无碰撞标注会报错；用mapLabels覆盖后仍校验。不能通过缩放变形道路或隐藏文字掩盖失败。
