# Open-Meteo 天气排错指南

最后核验：2026-09-10

官方文档：https://open-meteo.com/en/docs

天气由生成后的页面直接请求 `https://api.open-meteo.com/v1/forecast`。页面固定使用城市中心的WGS84坐标，不读取设备定位，也不在仓库中保存天气Key。

## 本项目使用的参数

- `latitude`、`longitude`：途中城市的多组坐标，顺序必须对应。
- `daily=weather_code,temperature_2m_max,temperature_2m_min`
- `forecast_days=3`
- `timezone=Asia/Shanghai`
- `temperature_unit=celsius`

页面只展示今天、明天、后天的基础天气、最高温和最低温。天气代码归并为晴、多云、阴、雾、雨、雪或雷雨。出发地和仅作为终点的城市不请求天气。

## 返回校验与降级

多坐标查询通常返回与输入坐标同序的数据组。每组必须同时具有3个日期、3个天气代码、3个最高温和3个最低温；顺序、长度或数值异常时，只把对应城市显示为“天气暂不可用”。

请求超时、网络断开、HTTP错误、无效JSON或城市数据缺失时，不读取旧缓存冒充当天预报，行程、地图和便利贴继续正常显示。

## 排错顺序

1. 在浏览器网络面板确认只发出一次批量天气请求。
2. 检查坐标数组长度相同，且使用WGS84而非GCJ-02。
3. 检查时区和三组daily字段名称。
4. 用单个城市坐标复现，区分服务异常与批量数据错位。
5. 若官方参数或返回结构变化，以官方文档为准，更新运行时代码和天气成功、缺失、过期、离线、超时测试。
