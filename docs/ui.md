# 固定视觉和交互


当前便利贴版是唯一视觉基准。提取模板时保留成熟样式和交互，不再要求每个 Agent 自行模仿其他网站。

- 主背景 `#F7F6D8`，外层/中性装饰 `#C4C19B`，文字和线条 `#11120F`。
- 点缀蓝 `#006699`、绿 `#009963`、黄 `#F3C543`、珊瑚红 `#E4572E`，小面积使用。
- 浅方格底纹、黑白像素小镇、阶梯轮廓和细线图标；不引入照片、大背景图、渐变卡片或新主题。
- 中文标题宋体，日期及数字等宽，正文系统中文字体，正文基准16px。已有天气、评价和小字按现有紧凑规范保留；不把正文也缩小成辅助字号。
- 以390px设计，验收360、390、430px及桌面。正文居中单列，地图桌面约960px宽；手机页面不能横向滚动。
- 左侧日期、城市、所属地区三行整体68px，与右侧天气上下对齐；所属地区窄屏11px、桌面12px。
- 统一内嵌 SVG 组件库。新增城市允许选用城镇、村寨、山水等已有装饰或按规范扩展原创图形。
- 地图本身不动画；正文像素汽车及小镇、天气有轻微分帧动画。保留手机兼容处理，系统减少动态效果时全部停用，隐藏页面时避免无效动画消耗。

## 6. H5 功能清单（继承并参数化）

### 页头与静态线路图

标题由旅程生成，不固定为当前地区名称。展示日期、起终点说明和右侧便利贴入口；不恢复页头下方已删除的短虚线，不恢复“每晚住哪里”独立模块。

线路图嵌入真实道路 SVG，保留比例、方向和相对位置；无地图脚本、拖动、缩放或在线地图请求。背景自然融入页面。

黑色单色路线与米黄色衬底，中性省界；少量黑色小箭头指示方向。箭头数量按路线长度与拥挤程度生成，沿用少而小原则，不写死为原行程的5个。

地图可见地名仅为确认的城市/县城，不显示具体景点或酒店名。游玩使用珊瑚红细描边旗帜；住宿用黑屋顶、黄房体、蓝门的简洁小屋。小屋紧邻城市名称右侧，同城连住合并图标，夜数仍在时间线中明确。

城市真实坐标不动，通过文字和引导折线避让；虚线有明确端点，不穿越文字或驾驶路线。对重复城市和密集节点做合并/错位排版，不通过非等比拉伸地图或底色盖线解决。

右上角展示动态计算的“总里程约 N KM”，下方紧凑图例“小屋 住宿、旗帜 游玩”，不加下划虚线。起终点不放大型箭头；只有专用起终点时不显示游玩或住宿标识。

### 城市时间线

每个途中停留段展示日期范围、城市/县城、所属市州、三日天气、推荐美食和抵达/游览/住宿/离开事件。城市间显示对应里程，正文道路旁配置错时运动的俯视像素汽车。

所有内容直接可读，不通过上一站/下一站隐藏正文。首尾同城仍是两个独立锚点；重复经过同一城市也用唯一段落 ID，不只用城市名作主键。

### 景点、口碑与链接

景点信息顺序固定：

1. 景点名称 · 具体位置 + 紧邻位置的高德小箭头。
2. 客观一句话介绍，不超过15个字。
3. “预计游玩 · 时长”。
4. “小红书网友”：一个正面图标接两条短语、一个中性/负面图标接两条短语；每条不超过5个字，同类用居中点分隔，一行展示，无边框和底色。

正文没有可靠中性或负面信息时，只展示已有的两条正面评价；整体证据不足时隐藏整个口碑模块。页面不显示短缺提示，也不编造缺点。

位置链接依可靠性使用正式 POI、坐标标记、或限定城市的搜索；泛地点不绑定虚假 POI。每道美食右侧有小红书搜索图标，尝试 App 唤起，失败保留网页搜索入口；无法保证所有系统和内置浏览器均允许自动唤起。

住宿事件醒目显示“住宿：城市”，旁边为“酒店待定 + 高德小图标”，默认城市酒店搜索；用户给出具体酒店后才替换为酒店 POI。

美食、位置、酒店图标约14px，外层约20px，去除常驻边框、背景、阴影，与文字间距2—4px；保留键盘焦点与说明标签，长地址可自然换行。

### 底部导航

常驻底栏约44px高、入口约38px，米黄色/黑色为主。所有停留段按行程顺序展示，首尾仅显示城市名；无障碍标签区分出发和返回。

城市之间用虚线加右箭头连接，连接符不参与点击。选中城市蓝色粗体、透明背景。点击立即选中并平滑定位；手动滚动按视口上方约三分之一处同步，城市间路段保持前一城市激活，任一时刻唯一 `aria-current`。

手机底栏可横滑，当前城市自动进入可视区，正文预留安全空间。减少动态效果时即时定位；打印隐藏底栏。长行程桌面也应允许横滑，不能挤压到不可读。

### 便利贴

页头按钮打开原生弹窗，手机约92%宽、桌面最大440px；关闭按钮、Esc和背景点击均可关闭；锁定背景滚动，关闭后焦点回到按钮。

默认8项：驾驶证和行驶证、身份证等随身证件、检查油量或电量、检查轮胎和胎压、ETC与导航设备、手机/充电线/充电宝、常用药和急救用品、饮用水与简单食物。

支持勾选、取消、删除、最多30字新增、回车提交，空白不添加。完成项弱化并加删除线。用户文本只以文本节点渲染；列表滚动时底部添加区保持可见。

本地保存包含版本和稳定 tripId，区分同域不同旅程；重新发布同一旅程不重置数据。删除全部保留空表；数据损坏或存储不可用时可继续操作。存储只属于同设备、浏览器和域名，本地文件清单不自动迁移到公网，不跨设备同步。
